# 🐍 Projetos Pessoais Python

Repositório criado para armazenar meus **projetos pessoais, exercícios e experimentos em Python**.

Estou utilizando este repositório para praticar programação, desenvolver minha lógica e aplicar os conceitos que estou aprendendo na linguagem Python.

## 📚 Sobre o repositório

Aqui serão adicionados projetos de diferentes níveis de dificuldade, desde exercícios básicos até projetos mais completos.

Alguns dos conceitos praticados incluem:

* Variáveis e tipos de dados
* Condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`for`, `while`)
* Listas, tuplas, conjuntos e dicionários
* Funções
* Manipulação de strings
* Entrada e saída de dados
* Algoritmos e lógica de programação
* Organização de projetos
* Bibliotecas e módulos Python
